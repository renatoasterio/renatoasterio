### Hey, I'm Renato 👋

**Dev, software architect and serial builder from Brazil.**
I turn "this should exist" into things that actually ship: SaaS products, native Mac apps and AI-powered tools.

I like software that feels fast, looks clean and solves one real problem well. If it annoys me twice, I'll probably build a fix for it.
